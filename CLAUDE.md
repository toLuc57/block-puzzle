## Current Feature Focus: Organic Boundaries & Selective Barriers

- Display grid expands to 12x10 while the playable puzzle area is centered and capped at 10x8.
- Player can cross puzzle boundaries, but all block types treat those boundary cells as solid barriers.
- Static geometry should stay TileMap-driven, while moving actors remain separate nodes spawned by `Main.gd`.
