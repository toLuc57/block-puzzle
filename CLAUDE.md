## Current Feature Focus: Sprout Lands Layout

- Water must cover the full game frame while Grass defines the 14x12 playable area with visual variation.
- Path is the orthogonal-only puzzle boundary; Crops are distinct static obstacles.
- Static geometry should stay TileMapLayer-driven, while moving actors remain separate nodes spawned by `Main.gd`.
